## 1. Пакетті дайындау

Дүкенге арналған нұсқаны құрастырғанда **нұсқа нөмірін беру міндетті**.
Онсыз құрастырылған пакетте әзірлеуге арналған артық рұқсат қалады да,
модерация оны сұрақ етіп қоюы мүмкін.

```bash
bash tools/make-mv3.sh chromium 1.0.0
python tools/make-store-zip.py
```

Нәтиже: `dist/tazakor-1.0.0-chromium.zip`

Скрипт архивті тексереді: `manifest.json` түбірде тұр ма, жол бөлгіштері
дұрыс па, әзірлеу рұқсаты қалып қойған жоқ па.

> Windows-та `zip` командасы жоқ, ал PowerShell-дің `Compress-Archive`
> командасы жол бөлгішін кері қиғаш сызық етіп жазады. Ондай архивті
> Chrome қабылдамайды. Сол себепті бөлек скрипт жазылған.

## 2. Әзірлеуші есептік жазбасы

<https://chrome.google.com/webstore/devconsole>

Тіркелу бетінде екі карточка болады, екеуін де орындау керек:

1. **Келісім.** Developer Agreement, Google құпиялық саясаты және бағдарлама
   ережелерімен танысып, құсбелгіні қою.
2. **Төлем.** Бір реттік тіркелу төлемі — **5 доллар США**. Төлем экранында
   осылай көрсетіледі (2026 жылдың қыркүйегінде тексерілген).

Төлемнен бұрын қай Google аккаунтында тұрғаныңды тексер. Аккаунттың поштасын
кейін өзгерту мүмкін емес, ал жойылған аккаунттың поштасын қайта пайдалану да
мүмкін емес.

Төлемнен кейін, бірақ жариялаудан бұрын, сол аккаунтта **екі факторлы растауды**
қосу міндетті. Онсыз кеңейтімді жариялау да, кейін жаңарту да мүмкін емес.

## 5. Рұқсаттар

«Privacy practices» бөлімінде үш нәрсе сұралады: бір сөйлемдік «Single
purpose», әр рұқсаттың негіздемесі және «Are you using remote code?»
деген сұраққа жауап. Үшеуінің де мәтіні `permissions.md` файлында дайын
тұр, ағылшынша.

Ең мұқият қаралатыны — `<all_urls>`. Онда толық режимнің не үшін
керегін және рұқсат берілмесе кеңейтім өзі негізгі режимге түсетінін
түсіндіру маңызды.

«Data usage» бөлімінде **бірде-бір санатты белгілеме**. Кеңейтім ешқандай
дерек жинамайды.

## 6. Модерациядан не күтуге болады

Форк болғандықтан, тексеру әдеттегіден ұзақ болуы мүмкін. Дүкен ережесі
бойынша басқа кеңейтімге ұқсас болып көрінуге тыйым салынған. Бізде
брендинг толық ауыстырылған, ал сипаттамада бұл форк екені ашық
жазылған, сондықтан мәселе тумауы тиіс.

Пакеттің ішінде `README.md` файлы бар, онда модератор құрастыруды
қалай қайталайтыны жазылған. Ол сұрақтарды азайтады.

Бас тарту келсе, себебі хатта жазылады. Көбіне рұқсаттардың негіздемесі
жеткіліксіз деп табылады, ондайда `permissions.md` мәтіндерін кеңейту
керек болады.

## 7. Материалдарды қайта жасау

```bash
python tools/make-store-shots.py   # HTML карталарды жасайды
python tools/make-store-zip.py     # архивті жасайды
```

Скриншот HTML файлдары құрастырылған кеңейтімнің папкасына жазылады,
себебі оларға кіріктірілген қаріп пен CSS керек. Chrome-мен рендерлеп
болған соң, оларды өшіру керек.
