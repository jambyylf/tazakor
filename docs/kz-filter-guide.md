# EasyList синтаксисі — қысқаша нұсқаулық

Бұл құжат `filters/kz.txt` файлына өз ережелеріңізді қосу үшін жазылған.

---

## 1. Қайда жазамын

Ережелер тек бір файлда: **`filters/kz.txt`**

Өзгерткеннен кейін кеңейтімді қайта құрастыру керек:

```bash
bash tools/make-mv3.sh chromium
```

Содан соң `chrome://extensions` бетінде ТазаКөр карточкасындағы **жаңарту**
белгішесін басыңыз. Тізім қосымша болғандықтан, оны баптаулардың
«Сүзгі тізімдері» бөлімінен қолмен қосу керек.

---

## 2. Түсініктеме

Леп белгісінен басталған жол ереже емес, түсініктеме:

```
! Бұл жол ескерілмейді
```

---

## 3. Желілік сүзгілер: сұранысты бұғаттау

Ең жиі қолданылатын түрі. Белгілі бір мекенжайға сұраныс жіберілмейді.

| Ереже | Не істейді |
|---|---|
| `\|\|reklama.kz^` | `reklama.kz` және оның барлық ішкі домендерін бұғаттайды |
| `\|\|kolesa.kz/banners/` | тек сол жолдағы файлдарды бұғаттайды |
| `\|\|cdn.example.kz^$third-party` | тек бөгде сайттан жүктелгенде бұғаттайды |
| `/ads/banner.js` | мекенжайдың кез келген жерінде осы мәтін кездессе |
| `-reklama-` | мекенжайда `-reklama-` тіркесі болса |

Белгілердің мағынасы:

- `||` — домен басы. `||kolesa.kz^` дегеніміз `kolesa.kz`, `www.kolesa.kz`,
  `m.kolesa.kz` — бәрі.
- `^` — бөлгіш: нүкте, қиғаш сызық, сұрақ белгісі немесе мекенжайдың соңы.
  Домен атауының дәл сол жерде бітуін талап етеді.
- `*` — кез келген мәтін. `||example.kz/*/ads` сияқты.
- `|` жалғыз тұрса — мекенжайдың дәл басы немесе дәл соңы.

---

## 4. Ерекшелік: бұғаттауды болдырмау

Екі айқыш белгісі `@@` бұғаттауды алып тастайды. Бір нәрсе қате бұғатталып,
сайт бұзылса осыны қолданыңыз.

```
@@||kolesa.kz/assets/player.js
```

Ерекшелік әрқашан бұғаттау ережесінен күштірек.

---

## 5. Опциялар

Ереженің соңына `$` қойып, шектеу қосуға болады. Бірнешеуін үтірмен бөледі.

| Опция | Мағынасы |
|---|---|
| `$third-party` | тек бөгде домендерден келген сұраныстар |
| `$script` | тек JavaScript файлдары |
| `$image` | тек суреттер |
| `$stylesheet` | тек CSS файлдары |
| `$xmlhttprequest` | тек фондық сұраныстар |
| `$domain=kolesa.kz` | тек осы сайтта әрекет етеді |
| `$domain=~kolesa.kz` | осы сайттан **басқа** жерде әрекет етеді |

Мысал:

```
||counter.example.kz^$third-party,script
||banner.example.kz^$domain=kolesa.kz|krisha.kz
```

## 6. Косметикалық сүзгілер: элементті жасыру

Екі тор белгісі `##` сұранысты бұғаттамайды, тек бетте көрінбейтін етеді.
Бұл жарнама орны бос ақ тіктөртбұрыш болып қалғанда керек.

```
kolesa.kz##.banner-top
krisha.kz##div[id="reklama"]
example.kz###ad-container
```

Сол жақта — сайт атауы, оң жақта — CSS селекторы.

- `.class-aty` — класы бойынша
- `#id-aty` — идентификаторы бойынша (сондықтан `###` үш тор болып тұр)
- `div[id="x"]` — атрибуты бойынша

Косметикалық ерекшелік `#@#` арқылы жасалады:

```
kolesa.kz#@#.banner-top
```

**Маңызды:** косметикалық сүзгілер тек «оңтайлы» және «толық» режимдерде
жұмыс істейді. «Негізгі» режимде олар қолданылмайды.

---

## 7. MV3-те жұмыс істемейтіндер

ТазаКөр Chrome-ның жаңа MV3 жүйесінде жұмыс істейді. Онда бірқатар шектеу бар.

**Жұлдызшалы домен деңгейі жұмыс істемейді:**

```
! ЖАРАМСЫЗ — құрастыру кезінде алынып тасталады
||reklama.*^$domain=example.*
```

Оның орнына нақты домендерді тізіңіз:

```
||reklama.kz^
||reklama.com^
```

**Скриптлеттер** (`##+js(...)`) тек «пайдаланушы скрипттері» рұқсаты
берілгенде істейді. Ол рұқсатты қолданушы қолмен қосуы керек.

**Күрделі тұрақты өрнектер** (regex) MV3-те шектеулі. Мүмкіндігінше
қарапайым үлгілерді қолданыңыз.

---

## 8. Қатені қалай табамын

Құрастырғаннан кейін журналды қараңыз:

```bash
grep -i "rejected\|unsupported" dist/build/uBOLite.chromium/log.txt
```

Егер ережеңіз қабылданбаса, ол осында себебімен жазылады. Сондай-ақ
баптаулардағы «Сүзгі тізімдері» бөлімінде әр тізімнің қанша ережесі
қабылданғаны көрсетіледі.

---

## 9. Жиі керек болатын мысалдар

Бүкіл жарнама доменін бұғаттау:

```
||adnetwork.kz^
```

Тек бір сайттағы жарнама блогын жасыру:

```
zakon.kz##.adv-block
```

Санауышты бұғаттау, бірақ өз сайтында тимеу:

```
||metrika.example.kz^$third-party,domain=~example.kz
```

Қате бұғатталған файлды қайтару:

```
@@||example.kz/js/player.js$script
```
