# Сайттарды өлшеу құралдары

`filters/kz.txt` тізіміндегі домендер ойдан жазылмаған, өлшеу арқылы
табылған. Бұл папкадағы скрипттер сол өлшеуді қайталауға мүмкіндік береді.

## Идея

Браузер бетті ашқанда ондаған сұраныс жібереді. Chrome соның бәрін журналға
жазып бере алады. Танымал қазақстандық сайттарды ашып, журналды жинаймыз да,
әр сұраныстың мекенжайын кеңейтімнің ережелерімен салыстырамыз. Ережеге
ілінбеген жарнама домендері — біздің тесіктеріміз.

## Қалай іске қосу

```bash
# 1. Кеңейтімді құрастыру (ережелер сол жерден оқылады)
bash tools/make-mv3.sh chromium

# 2. Сайттардан дерек жинау
mkdir -p /tmp/m/netlog /tmp/m/hosts
cp tools/measure/hosts.py /tmp/m/
bash tools/measure/collect.sh /tmp/m https://www.zakon.kz/ zakon
bash tools/measure/collect.sh /tmp/m https://www.nur.kz/ nur
# ... қалған сайттар

# 3. Талдау
python tools/measure/analyze.py dist/build/uBOLite.chromium /tmp/m/hosts
```

## Файлдар

| Файл | Не істейді |
|---|---|
| `collect.sh` | Бір сайтты ашып, хост атауларын жинайды |
| `hosts.py` | Chrome журналынан мекенжайларды шығарады |
| `matcher.py` | Хост біздің ережелерге ілінетінін тексереді |
| `analyze.py` | Бәрін біріктіріп, өтіп кететіндерін көрсетеді |

## Шектеулері

`matcher.py` — толық DNR қозғалтқышы емес. Ол тек домен деңгейіндегі
бұғаттауды қарайды, себебі жарнама домендеріне жазылатын ережелердің басым
бөлігі сондай. Сондықтан «бұғатталады» деген жауап сенімді, ал «өтіп кетеді»
деген жауапты қолмен тексерген жөн.

Кеңейтімді headless режимде жүктеп өлшеу жұмыс істемейді: Chrome ол режимде
кеңейтімді тиемейді. Сол себепті ережелер тікелей файлдан оқылады.

## Не қосуға болады, не қоспау керек

Өлшеу нәтижесінде шыққан хосттың бәрі жарнама емес. Мысалы:

- **Қосуға болмайды**: сайттың өз суреттер қоймасы (`*.kcdn.kz`), Yandex-тің
  сурет қызметтері (`avatars.mds.yandex.net`), браузердің қызметтік домендері
  (`csp.withgoogle.com`), әлеуметтік желі виджеттері.
- **Қосуға болады**: атауында `rtb`, `dsp`, `ssp`, `sync`, `pixel`, `bidder`,
  `dmp` сияқты жарнама инфрақұрылымына тән сөздер бар домендер, әсіресе
  бірнеше тәуелсіз сайтта қатар кездессе.

Күмән болса, қоспаған дұрыс. Қажетті нәрсені бұғаттап, сайтты бұзып алғаннан
гөрі, бір жарнаманы жіберіп алған жеңіл.
